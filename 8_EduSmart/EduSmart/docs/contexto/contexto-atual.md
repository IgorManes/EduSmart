# Contexto atual — EduSmart

O EduSmart é uma plataforma educacional para organizar cursos, turmas, professores, alunos, matrículas, avaliações, notas e comunicações acadêmicas.

## Atores

- aluno;
- professor;
- coordenação.

## Sistemas externos

- sistema acadêmico institucional;
- serviço de e-mail;
- serviço de SMS.

## Fluxo central observado no código

O sistema cadastra dados acadêmicos em memória, matricula alunos, cria avaliações, registra notas, calcula média final, publica eventos acadêmicos e fecha turmas. Há integrações legadas para publicação de notas e notificações.

Consulte também `../arquitetura/arquitetura-atual.md` e `../requisitos/requisitos-atualizados.md`.
